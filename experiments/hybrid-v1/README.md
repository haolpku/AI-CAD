# Hybrid v1

Hybrid v1 将“语义判断”和“数值计算”分开：LLM 只能从候选中选择证据 ID，不能输出工程量；数量、长度、面积和体积由确定性程序计算。

## 流程

1. `prepare-hybrid-evidence-v1.mjs`
   - 从 DWG 模型空间读取图块、文字和几何；
   - 使用附近的“平面图/系统图/图例/设计说明”标题对实体做空间分类；
   - 对图块插入点去重，分别记录平面、系统图和图例计数；
   - 重建 LINE、LWPOLYLINE 和 ARC 长度，统计连通分量、悬空端点及附近标注。
2. `run-semantic-map-v1.mjs`
   - 按目标检索最多 10 个候选 block/route 证据；
   - 模型只返回`evidenceIds`、置信度和解释；
   - 候选不足时返回`none`。
3. `execute-hybrid-v1.mjs`
   - 置信度达标时，对 block 的`planCount`或 route 的`planLengthM`求和；
   - 同一 route 被多个目标共享时拒绝替换；
   - 管道内/外表面积、保温体积和保护层面积由管长、管径和保温厚度确定性计算；
   - 未通过门控的目标保留 frozen baseline。

## Calibration 结果

| 版本 | Bench Score | Core | Derived |
|---|---:|---:|---:|
| 原 closed-world 盲测 | 26.51 | 30.53 | 10.40 |
| 只加 Derived 公式 | 27.29 | 30.53 | 14.34 |
| 只加语义证据执行 | 31.12 | 36.30 | 10.40 |
| Hybrid v1，阈值 0.85 | **34.68** | **36.30** | **28.20** |

关键分组变化：

- 防雷长度 WAPE：207.2% → 14.4%；
- 给排水核心长度 WAPE：133.5% → 71.2%；
- 照明数量 WAPE：56.8% → 50.2%；
- 派生面积 WAPE：99.1% → 51.4%；
- 派生体积 WAPE：53.6% → 16.4%。

0.85 阈值在 Case-001 calibration 上选定，因此 34.68 不得声称为隐藏测试或泛化成绩。下一个项目必须在看到真值前冻结该阈值、空间分类半径、图层过滤和公式表。

## 尚未解决

- 给排水管线仍有多个管径共用图层，需要按附近 DN 文字对拓扑边分段；
- 立管、标高和跨楼层线长尚未完整恢复；
- 端头数和超高长度仍保留 baseline；
- 外部参照内的重复实体还需要基于 xref 变换链的去重。
