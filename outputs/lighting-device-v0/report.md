# Case-001照明设备数量基线

> 当前数据划分：**calibration**。本项目用于规则校准，不能作为独立测试集宣称泛化能力。

## 结果

- 类别数：10
- 完全命中：2/10（20.0%）
- MAE：3.10 个/类别
- MAPE：15.8%
- WAPE：19.9%
- 真值总量：156；预测总量：127

## 当前边界

- 电线长度需要回路根数、敷设方式和预留规则
- 配管长度需要识别管线路由、跨层立管和暗敷规则
- 同一图层混入了非照明专业图块，需要语义过滤

## 架构结论

几何提取、数量计算和评分应保持为确定性 workflow；Codex SDK 适合用于生成候选映射规则、解释未映射图块、辅助复核和生成报告，不应直接替代几何计算器。
